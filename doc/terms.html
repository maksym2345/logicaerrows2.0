2. Description of the Game:

The website features a 2D game where arrows act as logic gates. The game operates on a square grid where you can place arrows into square cells. These arrows can be rotated in four directions aside from being flipped horizontally. The grid updates each game tick and all arrows perform their designated actions simultaneously. The game follows cellular automata rules.
