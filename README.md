# Logic Arrows 2.0

Редактор логічних схем (стрійки, датчики, дисплеї) з мультиплеєром.

## Запуск

Гра — один файл `index.html`, але мультиплеєр потребує сервера. Сервер написаний без жодних npm-залежностей, тому достатньо встановити Node.js 18+ і виконати:

```bash
node server.js
```

Відкрийте **http://localhost:3000** — гра підхопить сервер автоматично (`ws://localhost:3000`).

> Якщо відкрити `index.html` подвійним кліком (`file://`), сервер не підключиться: браузер заблокує з'єднання, і гра перейде в локальний режим.

## Мультиплеєр

Натисни **🌐 Мультиплеєр** у верхньому меню.

- **Хост** — «Створити кімнату», отримує 6-літерний код, ділиться ним.
- **Гість** — вводить код → «Підключитися».

Хост будує схему і розсилає стан; гості ставлять і знімають блоки — їхні дії летять хосту, той застосовує й повертає оновлення всім. Хост бачить список гравців і може вигнати будь-якого. Якщо з'єднання рветься, клієнт перепідключується сам (5 спроб) — гість повертається у ту саму кімнату.

### Гра з другом через інтернет

GitHub Pages гру **не озвучить**: це тільки статичні файли, там нема де запустити сервер мультиплеєра. Сторінка на `https://...github.io` взагалі не зможе підключитись до `ws://` — браузер ріже змішаний вміст мовчки, і гра просто перейде в локальний режим. Тому для гри з другом сервер має жити десь окремо.

Найпростіший безплатний варіант — Render:

1. Залогінься на [render.com](https://render.com) через GitHub.
2. **New+ → Blueprint** → вибери цей репозиторій. Файл `render.yaml` у репо вже все налаштував (Node, `node server.js`, health-check `/healthz`), тому Render сам запропонує створити сервіс — тисни **Apply**.
3. Через хвилину отримаєш адресу типу `https://logicaerrows-mp.onrender.com`. **Це і гра, і сервер одночасно** — кидай другу саме це посилання, нічого більше вписувати не треба.
4. Якщо хочеш грати з посилання Pages, тоді впиши адресу Render у полі «Адреса сервера» (на обох машинах), або заміни `MP_PUBLIC_WS` на початку блоку `МУЛЬТИПЛЕЄР` в `index.html` на свій URL.

Мінус безплатного тарифу: сервіс присипає без трафіку, і перше підключення після простою триває до хвилини — гра сама напише «Розбуджую сервер…» і перечекати замість того, щоб здатись.

### Інші варіанти мережі

- **У межах домашньої мережі** — хост запускає `node server.js`, гості відкривають `http://IP-ХОСТА:3000`. Порт 3000 має бути дозволений у брандмауері Windows.
- **Ззовні без хостингу** — пробрось порт 3000 на роутері й дай гостям публічну IP хоста; для `https`-сторінки знадобиться ще й `wss://` (сертифікат).
- У вікні «Адреса сервера» можна вписати будь-який `ws://...` чи `wss://...` — вибір запам'ятається в браузері.

### Локальний режим (без сервера)

Без доступного сервера гра сама переходить у локальний режим: синхронізація йде через `localStorage`, тому працює лише між вкладками одного браузера на одній машині.
